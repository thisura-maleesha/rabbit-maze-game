# 🐇 Rabbit Maze Game

![Processing](https://img.shields.io/badge/Built%20with-Processing-blue)
![Java](https://img.shields.io/badge/Language-Java-orange)
![Status](https://img.shields.io/badge/Status-Playable-brightgreen)

> Navigate a randomly generated maze as a rabbit and reach the 🥕 carrot before time or moves run out!

---

## 🎮 How to Play

| Control | Action |
|---------|--------|
| `W` or `↑` | Move Up |
| `S` or `↓` | Move Down |
| `A` or `←` | Move Left |
| `D` or `→` | Move Right |
| `R` | Restart Game |

---

## ⏱️ Rules

- ⏰ **Time Limit** — 55 seconds
- 👣 **Move Limit** — 75 moves
- 🥕 **Goal** — Reach bottom-right corner

---

## 🛠️ Requirements

- [Processing 4](https://processing.org/download)

## ▶️ Run

1. Clone or download this repo
2. Open `rabbit-maze-game.pde` in Processing
3. Click ▶️ Play!
